## Settings

### `PDBCTL_SOT_IX`

Controls whether or not PdbCtl is used to source IX data like Exchanges and their members. If distabled only exchanges from the connected IxCtl API will be loaded.

Default: `True`

### `DEFAULT_PAGE`

Which page to load by default when loading PeerCtl without a page specified.

Default: `home` which will convert to `peers` if there is only one ASN.
